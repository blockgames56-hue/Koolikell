# Koolikell — Автоматическая система школьных звонков

Приложение для автоматизации школьных звонков на базе Electron и React.

## Возможности

- **Расписание звонков**: настройка времени звонков на каждый день недели (понедельник – пятница), поддержка стандартного и сокращённого расписания.
- **Мелодии звонков**: загрузка аудиофайлов (MP3, WAV, WEBM, OGG, M4A, FLAC, AAC), визуальная нарезка отрывка.
- **Плавное затухание**: автоматическое приглушение и сведение громкости в ноль за 3 секунды до окончания звонка.
- **Фоновый режим**: сворачивание в системный трей Windows с сохранением работы таймеров.
- **Автозапуск**: запуск приложения вместе со стартом Windows.
- **Мультиязычность**: интерфейс на русском, эстонском и английском языках.
- **Выбор аудиоустройства**: маршрутизация звука на выбранные динамики или звуковую карту.

## Разработка и сборка

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

### Сборка приложения
```bash
npm run build
```

### Сборка EXE
```bash
npm run pack:exe
```
Готовый исполняемый файл создаётся в `release/win-unpacked/Koolikell.exe`.
