## 📖 О проекте

**Koolikell** (*«Школьный звонок»* на эстонском) — это надежное и гибкое решение для автоматической подачи звонков по расписанию через школьную систему оповещения или радиоузел. 

В отличие от устаревших механических таймеров или простых будильников, **Koolikell** спроектирован с учетом специфики учебных заведений: поддержка сокращенных дней, возможность установки индивидуальных мелодий на каждый урок, встроенный визуальный аудиоредактор и гарантированное срабатывание даже при работе в фоновом режиме.

## ✨ Основные возможности

### 📅 Управление расписанием
- **Стандартное и сокращенное расписание**: мгновенное переключение между обычным режимом и сокращенными уроками в праздничные или санитарные дни.
- **Расписание по дням недели (Пн–Пт)**: раздельная конфигурация звонков на каждый день и урок.
- **Интерактивный дашборд**: крупный таймер обратного отсчета до следующего звонка, статус системы и кнопка экстренной/ручной подачи звонка.

### 🎵 Медиатека и аудиоредактор
- **Широкая поддержка форматов**: `MP3`, `WAV`, `OGG`, `WEBM`, `M4A`, `FLAC`, `AAC`.
- **Встроенная визуальная нарезка (Waveform Trimmer)**: визуализация звуковой волны, выбор точного интервала звучания прямо в приложении без необходимости использовать сторонние редакторы.
- **Плавное затухание (Fade-Out)**: мягкое сведение звука в ноль за 3 секунды до окончания звонка для комфортного акустического восприятия.

### ⚙️ Системная интеграция
- **Маршрутизация звука**: выбор физического аудиоустройства (отдельной звуковой карты, усилителя трансляционной линии или внешних колонок) независимо от системного вывода по умолчанию.
- **Работа в фоне и системный трей**: сворачивание в трей без остановки таймеров и очередей звонков.
- **Автозапуск с Windows**: запуск в тихом режиме при включении компьютера оператора/дежурного.
- **Single Instance Lock**: защита от случайного параллельного запуска двух копий программы.

## 🚀 Установка и запуск

### Предварительные требования
- **Node.js** версии 18 или новее
- **npm** (поставляется вместе с Node.js)
- **ОС**: Windows 10 / 11

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/koolikell.git
cd koolikell
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```

## 📦 Сборка дистрибутива

Проект поддерживает автоматическую сборку как портативной версии, так и готового установщика.

```bash
# Полная компиляция проекта (TypeScript + Vite)
npm run build

# Создание распакованной сборки (win-unpacked)
npm run pack:exe

# Создание инсталлятора (NSIS) и Portable EXE в папку release/
npm run dist:exe
```

Собранные файлы будут доступны в директории `release/`:
- `release/Koolikell Setup 1.0.0.exe` — установщик
- `release/win-unpacked/Koolikell.exe` — распакованное приложение

## 🛡 Архитектура и надежность

В школьной среде критически важно, чтобы звонки не запаздывали из-за энергосбережения операционной системы или ухода процесса в спящий режим. В **Koolikell** внедрен комплекс оптимизаций:

1. **Защита от троттлинга Chromium**:
   ```typescript
   app.commandLine.appendSwitch('disable-background-timer-throttling');
   app.commandLine.appendSwitch('disable-renderer-backgrounding');
   app.commandLine.appendSwitch('disable-backgrounding-occluded-windows');
   ```
2. **Беспрепятственное автовоспроизведение**:
   Политика автоплея `no-user-gesture-required` позволяет приложению начинать воспроизведение точно в секунду расписания без ожидания клика пользователя.
3. **Собственный защищенный протокол**:
   Аудиофайлы транслируются через внутренний протокол `koolikell-sound://` с поддержкой `HTTP Range Requests`, что обеспечивает мгновенный поиск по аудиопотоку и сведение задержек воспроизведения к минимуму.
